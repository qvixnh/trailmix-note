# 🧠 2. Apex Class: `ParkLocator`

```apex
public class ParkLocator {
    public static List<String> country(String country) {
        ParkService.ParksImplPort stub = new ParkService.ParksImplPort();
        
        // Call SOAP service
        ParkService.byCountryResponse response = stub.byCountry(country);
        
        // Return list of park names
        List<String> parks = new List<String>();
        
        for (ParkService.park p : response.return_x) {
            parks.add(p.parkName);
        }
        
        return parks;
    }
}
```

# 🧪 3. Mock Class: `ParkServiceMock`

```apex
@isTest
global class ParkServiceMock implements WebServiceMock {
    
    global void doInvoke(
        Object stub,
        Object request,
        Map<String, Object> response,
        String endpoint,
        String soapAction,
        String requestName,
        String responseNS,
        String responseName,
        String responseType) {
        
        // Fake response
        ParkService.byCountryResponse res = new ParkService.byCountryResponse();
        
        ParkService.park p1 = new ParkService.park();
        p1.parkName = 'Yellowstone';
        
        ParkService.park p2 = new ParkService.park();
        p2.parkName = 'Yosemite';
        
        res.return_x = new List<ParkService.park>{ p1, p2 };
        
        response.put('response_x', res);
    }
}
```

# ✅ 4. Test Class: `ParkLocatorTest`

```apex
@isTest
private class ParkLocatorTest {
    
    @isTest
    static void testCountry() {
        // Set mock
        Test.setMock(WebServiceMock.class, new ParkServiceMock());
        
        // Call method
        List<String> result = ParkLocator.country('United States');
        
        // Assertions
        System.assertNotEquals(null, result);
        System.assertEquals(2, result.size());
        System.assertEquals('Yellowstone', result[0]);
        System.assertEquals('Yosemite', result[1]);
    }
}
```

# ⚠️ Lưu ý quan trọng (dễ fail)

* `ParkService` phải đúng tên (Trailhead check rất chặt)
* Method phải tên: `country`
* Return: `List<String>`
* Mock phải dùng `WebServiceMock`
* Key trong response map phải là `'response_x'`
