### 1. Apex Trigger

```apex
trigger OrderEventTrigger on Order_Event__e (after insert) {
    List<Task> tasks = new List<Task>();

    for (Order_Event__e event : Trigger.New) {
        if (event.Has_Shipped__c == true) {
            Task t = new Task();
            t.Priority = 'Medium';
            t.Subject = 'Follow up on shipped order ' + event.Order_Number__c;
            t.OwnerId = event.CreatedById;
            tasks.add(t);
        }
    }

    if (!tasks.isEmpty()) {
        insert tasks;
    }
}
```

---

## ⚠️ NOTE QUAN TRỌNG (để pass)

* MUST dùng: `after insert`
* Object: `Order_Event__e`
* Check: `Has_Shipped__c == true`
* OwnerId: `event.CreatedById` (đúng requirement đề bài)
